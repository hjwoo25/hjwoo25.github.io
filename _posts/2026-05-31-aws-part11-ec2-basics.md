클라우드 하면 가장 먼저 떠오르는 서비스, **EC2**입니다.  
온프레미스 서버를 직접 사고 설치하고 유지보수하던 시대에서,  
버튼 몇 번으로 전 세계 어디서든 서버를 띄울 수 있는 시대로의 전환을 이끈 핵심 서비스입니다.

---

## Amazon EC2란?

> **정의:** 클라우드에서 안전하고 크기 조정이 가능한 컴퓨팅 파워를 제공하는 웹 서비스

> **한 줄 비유:** AWS라는 거대한 데이터센터에서 **필요한 만큼만 빌려 쓰는 가상 서버**입니다.  
> 마치 렌터카처럼, 필요할 때 빌리고 다 쓰면 반납합니다.

EC2는 **Elastic Compute Cloud**의 줄임말로, 'Elastic'이라는 단어처럼 필요에 따라 유연하게 크기를 늘리거나 줄일 수 있는 것이 핵심입니다.

---

## EC2의 4가지 주요 장점

### ① 초 단위 온디맨드 가격 모델

> **비유:** 택시처럼 탄 만큼만 냅니다.

- 서비스 요금을 **미리 약정하거나 선입금할 필요 없음**
- **초 단위**로 과금 → 1시간을 빌려도 실제 30분만 썼으면 30분치만 납부

```
기존 온프레미스:
서버 구매 → 설치 → 유지보수 → 몇 년치 비용 한번에 선납 💸

EC2:
인스턴스 시작 → 사용 → 중지 → 사용한 시간(초)만큼만 납부 ✅
```

---

### ② 빠른 구축과 확장성

> **비유:** 레고 블록처럼 필요할 때 바로 쌓고, 불필요하면 바로 뺄 수 있습니다.

- **단 몇 분** 만에 전 세계에 수백여 대의 인스턴스를 구축 가능
- 트래픽이 급증하면 인스턴스를 추가하고, 줄어들면 다시 축소

```
블랙프라이데이 이벤트 전날:
서버 10대 → 100대로 증설 (클릭 몇 번, 몇 분 내) ✅

이벤트 종료:
100대 → 다시 10대로 축소, 추가 비용 없음 ✅
```

---

### ③ 다양한 구성 방법 지원

> **비유:** 용도별로 최적화된 차량을 고르는 것처럼, 목적에 맞는 인스턴스 타입을 선택합니다.

| 사용 목적 | 적합한 인스턴스 |
|---|---|
| 일반 웹서버, 개발 환경 | 범용 (t, m 시리즈) |
| 머신러닝, GPU 가속 | 가속 컴퓨팅 (g, p 시리즈) |
| 게임 서버, 고성능 연산 | 컴퓨팅 최적화 (c 시리즈) |
| 대용량 데이터베이스 | 메모리 최적화 (r, x 시리즈) |

여러 **과금 모델**(온디맨드, 예약, 스팟 등)도 제공하여 비용 최적화가 가능합니다.

---

### ④ AWS 생태계 연동

> **비유:** EC2는 AWS라는 거대한 레고 세트에서 가장 중심이 되는 블록입니다.

EC2는 독립적으로도 강력하지만, 다른 AWS 서비스와 연동할 때 진가를 발휘합니다.

| 연동 서비스 | 역할 |
|---|---|
| **Auto Scaling** | 트래픽에 따라 EC2 대수를 자동으로 조절 |
| **ELB (Elastic Load Balancer)** | 여러 EC2에 트래픽을 균등하게 분산 |
| **CloudWatch** | EC2의 CPU, 메모리, 네트워크 상태를 모니터링 |
| **IAM** | EC2에 역할을 부여해 다른 AWS 서비스 접근 권한 관리 |

---

## EC2가 해결하는 문제

기존 온프레미스 환경에서 겪던 고질적인 문제들을 EC2가 어떻게 해결하는지 비교해봅니다.

| 문제 | 온프레미스 | EC2 |
|---|---|---|
| 초기 비용 | 서버 구매 비용 수천만원 | 없음 (사용 즉시 과금) |
| 구축 시간 | 수일~수주 | 수분 |
| 용량 조정 | 서버 추가 구매 필요 | 클릭 몇 번으로 즉시 확장 |
| 유지보수 | 직접 관리 (하드웨어 교체 등) | AWS가 물리 인프라 관리 |
| 글로벌 확장 | 해외 데이터센터 직접 구축 | 리전 선택만으로 해외 배포 가능 |
