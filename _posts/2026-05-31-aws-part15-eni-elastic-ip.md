EC2 인스턴스가 네트워크와 통신하는 방식을 이해하려면 **ENI**와 **Elastic IP**를 알아야 합니다.  
보안 그룹이 실제로 어디에 붙는지, 퍼블릭 IP를 어떻게 고정하는지가 여기서 결정됩니다.

---

## ENI (Elastic Network Interface)

> **정의:** VPC에서 가상 네트워크 카드를 나타내는 논리적 네트워킹 구성 요소

> **비유:** EC2가 컴퓨터 본체라면, ENI는 그 본체에 꽂혀 있는 **랜카드**입니다.  
> 랜카드를 바꾸면 IP와 MAC 주소가 바뀌는 것처럼, ENI를 교체하면 네트워크 정보가 통째로 이동합니다.

### ENI의 핵심 특성

| 특성 | 내용 |
|---|---|
| **보유 정보** | IP 주소, MAC 주소 |
| **복수 연결** | 하나의 인스턴스에 여러 ENI 부착 가능 → 결과적으로 한 인스턴스가 여러 IP 보유 |
| **IP 개수 제한** | 인스턴스 유형과 크기에 따라 보유 가능한 최대 IP 수가 다름 |
| **기본 IP 유형** | Private IP + Private 도메인 기본 보유 |
| **선택적 부여** | Public IP + Public 도메인은 선택적으로 부여 |

### 보안 그룹은 ENI에 붙는다

많은 분들이 "보안 그룹이 EC2에 붙는다"고 이해하지만, 정확히는 **ENI에 부착**됩니다.

```
[일반적인 이해]
EC2 인스턴스 ← 보안 그룹 적용

[정확한 구조]
EC2 인스턴스
  └── ENI (랜카드) ← 보안 그룹이 여기에 부착
        ├── IP 주소
        └── MAC 주소
```

ENI가 인스턴스에서 분리되어 다른 인스턴스에 붙으면, **보안 그룹 설정도 함께 이동**합니다.  
이를 활용하면 장애 발생 시 ENI를 통째로 옮겨 빠르게 트래픽을 전환할 수 있습니다.

---

### ENI 활용 시나리오

```
[시나리오: 인스턴스 장애 대응]

인스턴스 A (장애 발생)
  └── ENI-1 (고정 IP: 10.0.0.10)

  ↓ ENI-1을 분리해서 인스턴스 B에 부착

인스턴스 B (정상)
  └── ENI-1 (고정 IP: 10.0.0.10) ← 동일 IP로 트래픽 계속 수신 ✅
```

## Elastic IP (탄력적 IP)

> **정의:** EC2의 퍼블릭 IP를 **고정**해주는 서비스

> **비유:** 일반 퍼블릭 IP가 임시 숙소(이사할 때마다 주소가 바뀜)라면,  
> Elastic IP는 **내 소유의 집 주소**입니다. 어느 인스턴스로 이사해도 주소는 그대로입니다.

### 왜 필요한가?

```
[Elastic IP 없이]
EC2 시작 → 퍼블릭 IP: 54.100.200.1
EC2 중지
EC2 재시작 → 퍼블릭 IP: 13.209.100.55 (변경됨!)

→ DNS에 등록해둔 IP가 틀려져서 서비스 접속 불가 ❌

[Elastic IP 사용]
EC2 중지 → 재시작해도 항상 같은 IP 유지 ✅
```

### Elastic IP의 주요 특성

| 특성 | 내용 |
|---|---|
| **적용 대상** | EC2뿐 아니라 NLB 등 다른 AWS 서비스에도 사용 가능 |
| **IP 이식** | 고객이 기존에 보유한 IP 주소를 AWS로 가져와서 사용 가능 (BYOIP) |
| **관리 단위** | 리전(Region) 단위로 생성 및 관리 |
| **기본 제공** | 계정당 리전별 기본 5개 (한도 증가 신청 가능) |

### 주의: 사용하지 않으면 비용 발생

> **⚠️ 중요:** Elastic IP를 할당받아 놓고 EC2 인스턴스에 **연결하지 않은 채** 보유만 하고 있으면 **IPv4 비용이 발생**합니다.

```
[비용 발생 케이스]
Elastic IP 할당 → EC2에 미연결 → 비용 청구 ❌

[비용 없는 케이스]
Elastic IP 할당 → 실행 중인 EC2에 연결 → 비용 없음 ✅

→ 사용하지 않는 Elastic IP는 반드시 해제(Release)할 것!
```

## ENI vs Elastic IP 관계 정리

```
EC2 인스턴스
  └── ENI (랜카드)
        ├── Private IP (항상 고정)
        ├── Public IP (중지/재시작 시 변경)
        └── Elastic IP (선택적 연결, 영구 고정) ← 여기에 Elastic IP가 연결됨
```

| 항목 | ENI | Elastic IP |
|---|---|---|
| **역할** | 네트워크 인터페이스 (랜카드) | 퍼블릭 IP 고정 서비스 |
| **Private IP** | ENI가 보유 | 해당 없음 |
| **Public IP 고정** | 기본적으로 불가 | Elastic IP로 고정 |
| **이동 가능 여부** | ENI째로 다른 인스턴스에 이동 가능 | 다른 인스턴스에 재연결 가능 |
