S3를 구성하는 핵심 요소인 버킷(Bucket)과 객체(Object), 그리고 S3가 자랑하는 '절대 파일을 잃어버리지 않는' 내구성과 비용 구조에 대해 알아봅니다.

---

## 버킷(Bucket)과 객체(Object)

S3는 블록 스토리지(EBS)나 네트워크 파일 스토리지(EFS)와 달리 어플리케이션 설치가 불가능한 순수 객체 스토리지입니다[cite: 7]. 

### 버킷 (Bucket)

- S3의 저장 공간을 구분하는 가장 큰 단위(최상위 디렉토리/폴더 개념)입니다[cite: 7].
- 🚨 **중요 규칙:** 버킷 이름은 전 세계 AWS를 통틀어 고유해야 하며, 리전에 관계없이 중복된 이름이 존재할 수 없습니다[cite: 7].

### 객체 (Object) 구성 요소

파일을 단순히 데이터로만 저장하는 것이 아니라, 여러 정보를 한 덩어리로 묶어 객체로 보관합니다[cite: 7]. 하나의 객체는 0byte에서 최대 50TB까지 저장할 수 있습니다[cite: 7].

| 구성 요소 | 설명 |
|---|---|
| **Key** | 파일의 이름[cite: 7] |
| **Value** | 파일의 실제 데이터[cite: 7] |
| **Metadata** | 파일의 정보를 담은 데이터[cite: 7] |
| **Version Id** | 파일의 버전 아이디[cite: 7] |
| **Owner / ACL** | 소유자 및 파일의 권한을 담은 데이터[cite: 7] |

## 99.999999999%의 내구성

> **비유:**
> S3에 올린 파일을 시스템 오류로 잃어버릴 확률(0.000000001%)은, **로또 1등에 당첨될 확률(0.00000012277%)보다 약 122배나 더 희박**합니다[cite: 7].

- **분산 저장:** 스탠다드 클래스 기준으로, 데이터를 최소 3개의 가용영역(AZ)에 분산 저장하여 99.999999999%(11 9s)의 내구성을 보장합니다[cite: 7].

## S3의 비용 구조

S3를 사용할 때 발생하는 요금은 크게 세 가지로 나뉩니다.

1. **보관 비용:** GB당 비용이 발생합니다 (예: 0.023 USD)[cite: 7].
2. **요청 비용:** PUT, COPY, POST, LIST 등 S3에 API 요청을 보낼 때 1,000개당 비용이 발생합니다[cite: 7].
3. **데이터 전송 비용:** S3에서 외부로 데이터를 다운로드(전송)할 때 GB당 비용이 발생합니다[cite: 7].
