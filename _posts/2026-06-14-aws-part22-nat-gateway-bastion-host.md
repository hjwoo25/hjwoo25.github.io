프라이빗 서브넷에 있는 서버는 외부로 나갈 수 없고, 외부에서 들어올 수도 없습니다. 그런데 보안 패치 다운로드나 관리자 접속은 어떻게 할까요? 이 두 가지 현실적인 고민을 해결하는 NAT Gateway와 Bastion Host를 정리합니다.

---

## NAT Gateway / NAT Instance — 밖으로 나가는 심부름꾼

> **비유:** 지하 금고(프라이빗 서브넷)에서 일하는 직원은 보안 규칙상 밖으로 절대 나갈 수 없습니다.  
> 그런데 외부 거래처에서 서류(업데이트 패치)를 받아와야 합니다.  
> 이때 1층 로비(퍼블릭 서브넷)에 있는 **대리인(NAT Gateway)**에게 부탁합니다.  
> 대리인이 밖으로 나가서 서류를 받아온 다음, 다시 지하 금고의 직원에게 전달해 주는 방식입니다.  
> 대리인 덕분에 지하의 직원은 밖으로 나갈(노출될) 필요가 없습니다.

프라이빗 서브넷 안에 있는 리소스(서버)가 외부 인터넷망으로 데이터를 요청하고 받아올 수 있게 해주는 **'통로'** 역할입니다.

### 핵심 역할

프라이빗 서브넷에 있는 인스턴스에서 **인터넷에 쉽게 연결**할 수 있도록 지원합니다.

### 위치 (매우 중요)

외부 인터넷과 통신해야 하므로, 이 통로 역할을 하는 장비는 반드시 **퍼블릭 서브넷(Public Subnet)에 위치**해야 합니다.

### 종류와 차이점

| 항목 | NAT Instance | NAT Gateway |
|---|---|---|
| **정의** | 사용자가 단일 EC2 인스턴스를 만들어서 직접 통로 역할을 세팅 | AWS에서 자체적으로 제공하는 **관리형 서비스** |
| **고가용성** | 직접 구성해야 함 | 기본적으로 확보되어 있음 |
| **실무 권장** | — | 대부분 이것을 사용 |

### 고가용성 확보 제약

NAT Gateway와 Instance는 모두 **하나의 서브넷 단위**로 동작합니다. 따라서 데이터센터(AZ) 하나가 마비되는 상황에 대비해 진정한 고가용성을 확보하려면, **두 개 이상의 가용영역(서브넷)에 각각 하나씩** 만들어 주어야 합니다.

### 비용 (서울 리전 기준)

유료 서비스이며 다음 요금이 부과됩니다:

| 항목 | 비용 |
|---|---|
| 시간당 | **$0.059** |
| 데이터 처리 1GB당 | **$0.045** |

## Bastion Host — 안으로 들어가는 안전문

> **비유:** 외부 도로에서 은행의 지하 금고(프라이빗 서브넷)로 바로 뚫려있는 문은 없습니다.  
> 은행장(관리자)이 지하 금고에 가려면 반드시 1층 로비(퍼블릭 서브넷)에 있는 **보안 경비실(Bastion Host)**의 문을 먼저 열고 들어가야 합니다.  
> 이 경비실에서 신분 확인(접속 인증)을 마친 사람만 내부 전용 엘리베이터를 타고 지하 금고의 서버로 들어갈 수 있습니다.

이번에는 반대로 **관리자가 프라이빗 서브넷 내부로 들어가기 위한 방법**입니다.

### 핵심 역할

외부에서 사설 네트워크에 접속할 수 있도록 **경로를 특별히 확보해 주는 서버**입니다. 프라이빗 서브넷 안의 리소스(예: DB 서버)에 접근하여 명령을 내리기 위해 **징검다리처럼 거쳐 가는 EC2 인스턴스**를 말합니다.

### 위치 (매우 중요)

관리자가 외부 인터넷 망에서 제일 먼저 접속을 해야 하므로, 이 서버 역시 반드시 **퍼블릭 서브넷(Public Subnet)에 위치**해야 합니다.

## 전체 그림 요약 (구조도 흐름)

### 내부 서버가 인터넷으로 나갈 때

```
가용영역 B: 프라이빗 서브넷의 EC2 (업데이트 요청)
    ↓
가용영역 A: 퍼블릭 서브넷의 NAT Gateway
    ↓
라우트 테이블 → 인터넷 게이트웨이(IGW)
    ↓
외부 인터넷
```

### 외부 관리자가 내부 서버에 접속할 때

```
외부 인터넷의 개발자/관리자
    ↓
인터넷 게이트웨이(IGW)
    ↓
퍼블릭 서브넷의 Bastion Host(EC2)에 접속
    ↓
프라이빗 서브넷의 내부 EC2로 안전하게 원격 접속
```

### NAT Gateway vs Bastion Host 비교

| 항목 | NAT Gateway | Bastion Host |
|---|---|---|
| **방향** | 안 → 밖 (Outbound) | 밖 → 안 (Inbound) |
| **목적** | 프라이빗 서버가 인터넷에서 패치/데이터 다운로드 | 관리자가 프라이빗 서버에 접속하여 관리 |
| **위치** | 퍼블릭 서브넷 | 퍼블릭 서브넷 |
| **형태** | AWS 관리형 서비스 또는 EC2 | EC2 인스턴스 |
