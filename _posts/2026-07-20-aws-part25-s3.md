가장 대중적이고 강력한 클라우드 저장소인 Amazon S3의 기본 개념을 알아봅니다. 내 컴퓨터의 C드라이브(파일 스토리지)와 S3(객체 스토리지)가 어떻게 다른지 명확하게 비교해 정리합니다.

---

## Amazon S3 (Simple Storage Service)란?

> **비유:**
> - **파일 스토리지 (C드라이브):** 폴더 안에 게임을 설치하고 바로 실행할 수 있는 내 컴퓨터의 하드디스크입니다.
> - **객체 스토리지 (S3):** 구글 드라이브나 웹하드처럼 인터넷에 파일을 올려두고 다운로드받는 무한대의 마법 창고입니다. 여기에 게임을 설치해서 실행할 수는 없습니다.

Amazon S3는 AWS에서 제공하는 업계 최고의 확장성과 데이터 가용성, 보안 및 성능을 제공하는 **객체(Object) 스토리지 서비스**입니다[cite: 6]. 

### 파일 스토리지 vs 오브젝트 스토리지

| 항목 | 파일 스토리지 | 오브젝트 스토리지 (S3) |
|---|---|---|
| **관리 방식** | 파일을 계층 구조(폴더)로 관리[cite: 6] | 파일을 오브젝트(데이터, 메타데이터, 아이디) 단위로 관리[cite: 6] |
| **장점** | 빠르게 찾고 업데이트 작업 가능[cite: 6] | 확장이 매우 쉬움 (수십 페타바이트 이상)[cite: 6] |
| **단점/한계** | 확장이 제한적임 (수십 테라바이트 수준)[cite: 6] | 정확한 경로를 알아야 찾기 가능[cite: 6] |
| **쉬운 구분** | 게임을 설치해서 사용 가능[cite: 6] | 웹하드처럼 게임 설치 불가능[cite: 6] |

### 언제 S3를 사용할까?

- 미디어, 로그, 소스코드, 파일, 백업 등 파일을 저장하고 활용하고 싶을 때 사용합니다[cite: 6].
- **Static Hosting (정적 웹 호스팅):** 서버(EC2) 없이도 웹페이지를 배포하고 제공하고 싶을 때 유용합니다[cite: 6].
